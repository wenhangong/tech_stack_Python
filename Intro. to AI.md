# 07 Problem Solving and Path Finding
### 01 Steps in Problem Solving
- Understanding the Problem: Analyze the requirements and constraints.
- Planning the Solution: Develop an algorithm or strategy.
- Implementing the Solution: Write code using a suitable programming language.
- Testing the Solution: Verify if the solution works for all cases.
- Optimizing the Solution: Improve efficiency and performance

### 02 Techniques Used in Problem Solving
- Algorithms: Step-by-step procedures to solve problems.
- Data Structures: Organizing data efficiently (e.g., arrays, trees, graphs).
- Divide and Conquer: Breaking problems into sub-problems (e.g., mergesort).
- Dynamic Programming: Solving overlapping subproblems (e.g., Fibonacci sequence).
- Greedy Algorithms: Making the best local choice at each step (e.g., shortest path).
